<h1>Модуль Cashback (Yii2)</h1>

<p>
Модуль <strong>Cashback</strong> реализует систему начисления кэшбэка при закрытии займа. 
Архитектура основана на принципах разделения ответственности, использовании DTO, 
репозиториев, валидаторов и сервисов.
</p>

<h2>Основные возможности</h2>

<ul>
    <li>Создание и редактирование правил начисления кэшбэка</li>
    <li>Валидация входных данных через DTO и слой валидаторов</li>
    <li>Транзакционное начисление кэшбэка</li>
    <li>Логирование выполнения правил</li>
    <li>Работа с кредитными продуктами и условиями правил</li>
    <li>Модульная структура, удобная для тестирования и расширения</li>
</ul>

<h2>Архитектура</h2>

<p>Модуль разделён на слои, каждый из которых отвечает за свою зону ответственности:</p>

<pre>
cashback/
├── Module.php
├── dto/                  – DTO объекты для передачи и валидации данных
├── models/               – ActiveRecord модели (Rule, RuleLog)
├── repositories/         – Репозитории и их интерфейсы
├── services/             – Бизнес-логика (правила, логи)
├── transformers/         – Преобразование данных (модели ↔ DTO)
└── validators/           – Валидаторы входящих данных и правил
</pre>

<h3>Сервисы</h3>
<ul>
    <li><strong>RuleService</strong> — создание, редактирование и активация правил</li>
    <li><strong>RuleLogService</strong> — сохранение логов выполнения правил</li>
</ul>

<h3>Репозитории</h3>
<p>Работают с БД и имеют интерфейсы для тестируемости:</p>
<ul>
    <li>RuleDbRepository</li>
    <li>RuleLogDbRepository</li>
    <li>CreditProductsDbRepository</li>
</ul>

<h3>DTO</h3>
<ul>
    <li>RuleValidateDto</li>
    <li>RuleLogDto</li>
</ul>

<h3>Трансформеры</h3>
<p>Отвечают за преобразование данных между слоями.</p>

<h3>Валидаторы</h3>
<p>Проверяют корректность бизнес-условий кэшбэка.</p>
